## Локальные тесты, транспорт подменён

- В каждом из четырёх репозиториев лежит `tests/consent-metrika.cjs`. По 9 сценариев прошли: до выбора и после отказа нет запроса; после разрешения ровно один `init` и `hit`; ID и цели совпадают с реестром; UTM/yclid сохраняются; чувствительный query не запускает тег; отзыв при ошибке `localStorage.setItem` вызывает `destruct` и блокирует новые цели; отзыв из другой вкладки останавливает счётчик; старая версия выбора запрашивается снова; на мобильном и без JavaScript контакт доступен. Новые поля ввода получают защитные классы.
- Тест перехватывает `mc.yandex.ru` и подставляет тестовый JS. Это проверка кода, **не доставка события** в настоящий счётчик и не проверка реального Вебвизора.
- На каждом сайте локально открыты главная, вложенная страница, политика и отдельный текст выбора при 1440 и 390 px: все 8 сочетаний на сайт вернули 200 и заголовок; с выключенным выпускным флагом не было запроса к `mc.yandex.ru`.
- `node --check` для изменённых JS выполнен на четырёх сайтах. Moscow: `npm run check`, `npm run build` (12 страниц). `git diff --check` выполнен на всех четырёх ветках.

## Как повторить

Нужны Node.js, установленный Chrome и пакет Playwright. В корне каждого проекта: `npm install --no-save playwright`, затем `node tests/consent-metrika.cjs js/consent-metrika.js` (Agency), `assets/consent-metrika.js` (Craft), `public/assets/consent-metrika.js` (Moscow) или `site-final/consent-metrika.js` (Hudwagen). Путь к Playwright можно передать через `PLAYWRIGHT_MODULE`; личные пути и профиль Chrome в тесте не зашиты. `node_modules` в PR не добавляется.

## Что остаётся для настоящей приёмки

После отдельного разрешения выпуска: добровольный визит на каждый опубликованный сайт, согласие, один переход по контакту без звонка/сообщения, проверка ID и поступления визита/цели в своём кабинете, проверка безопасной записи Вебвизора и карт, отзыв и отсутствие новых запросов. Отчёты могут появляться с задержкой. HTTP 200 или локальная подмена не считаются подтверждением приёма. Рабочий трафик намеренно не генерировался.

Права Agency в Яндекс Вебмастере и Hudwagen в Яндекс Вебмастере, Google Search Console и Bing подтверждены после отдельной публикации файла/метатегов. Подтверждение прав не проверяет доступность HTTPS: оба адреса Hudwagen по-прежнему показывают ошибку сертификата. Sitemap Hudwagen не отправлен, поскольку публичный файл указывает на GitHub Pages.
