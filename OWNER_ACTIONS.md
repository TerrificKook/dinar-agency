# Конкретные решения владельца перед запуском

| Сайт | Недостающая информация или действие | Для чего |
| --- | --- | --- |
| Dinar.agency | Подтвердить фактического оператора обращений/аналитики и адрес для запросов о данных; статус уведомления РКН | Завершить публичную политику и оценить правовое основание запуска |
| DINAR handmade | Подтвердить по выписке ИП 12-значный ИНН, ОГРНИП и адрес для обращений; определить порядок подачи уведомления РКН, которое от ИП ещё не подавалось | Не публиковать выдуманные реквизиты и юридически завершить политику |
| Dinar Moscow | Подтвердить фактического оператора, адрес для обращений и статус уведомления РКН | Завершить публичную политику до активации Метрики |
| Hudwagen | Подтвердить фактического оператора, адрес для обращений и статус уведомления РКН; дождаться выпуска корректного HTTPS-сертификата для `www.hudwagen.ru` и проверить оба адреса; отдельно согласовать исправление публичного sitemap/robots/canonical | Завершить политику и открыть канонический HTTPS; поисковые права Google/Bing уже подтверждены |

Минимальная публикация подтверждения поисковых прав выполнена 29.09.2026. Для слияния и включения четырёх аналитических PR требуется отдельное решение после юридической проверки; это другой выпуск. Логин Марата для технического счётчика не требуется. REG.RU сейчас оплачивает только почту DinarCraft; почта, DNS, хостинг и платные услуги не менялись.
