# dinar-agency

Статический сайт `dinar.agency`.

## Структура

- `index.html` — главная страница.
- `css/style.css` — стили главной.
- `js/main.js` — меню, форма первого контакта и аналитика.
- `fishki-biznesa/` — публичная «Лаборатория» с карточками, PDF и генератором промта.
- `docs/` — аудит, концепция, журнал изменений и описание защиты контактов.

## Локальный запуск

В папке проекта:

```powershell
node serve-local.js
```

После запуска открыть:

```text
http://localhost:8000/
http://localhost:8000/fishki-biznesa/
```

Отдельная сборка не требуется: сайт состоит из HTML, CSS и JavaScript.

Остановить локальный сервер можно сочетанием `Ctrl+C`.
