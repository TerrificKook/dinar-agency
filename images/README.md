# Images upload guide

For the About section portrait, upload your file to:

- `images/dinar-about-photo.jpg`

The site is configured to use this file in the About section.
If the file is missing, it falls back to `images/dinar-photo.png`.

The social preview image for the main site is:

- `images/og-dinar-agency-v04.png`

The previous main-site cover is preserved as `images/og-dinar-agency.png`.
The Laboratory uses its own cover at `fishki-biznesa/assets/og-cover.png`.
