# Раздел «Фишки бизнеса»

Этот раздел живёт внутри сайта Dinar Agency по адресу:

```text
https://dinar.agency/fishki-biznesa/
```

## Где что менять

- Карточки, категории, советы, PDF и ссылки: `data/content.js`
- Внешний вид раздела: `css/style.css`
- Логика поиска, фильтров, копирования и генератора: `js/main.js`
- Основная разметка страницы: `index.html`
- PDF-файлы: `assets/pdf/`

## Как добавить новую фишку

Откройте `data/content.js` и добавьте новый блок в список `catalog`:

```js
{
  category: "Контент",
  title: "Название фишки",
  description: "Короткое описание",
  text: "Текст промта или шаблона"
}
```

Категория появится в фильтрах автоматически.

## Как заменить PDF

1. Положите новый PDF в `assets/pdf/`.
2. Если имя файла осталось `30-chatgpt-prompts.pdf`, больше ничего менять не нужно.
3. Если имя другое, обновите ссылку `href` в списке `pdfs` в `data/content.js`.

## Как поменять ссылку на Telegram

В `data/content.js` измените:

```js
links: {
  telegram: "https://t.me/...",
  contact: "https://t.me/mrdinar"
}
```

## Как проверить локально

Откройте файл:

```text
fishki-biznesa/index.html
```

Проверьте: поиск, фильтры, открытие карточки, копирование, PDF и ссылку на Telegram.
